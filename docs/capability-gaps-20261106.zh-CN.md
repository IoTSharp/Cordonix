# 高频能力缺口：2026-11-06 第一批实施

本批依据已完成的本机审计选取三个切片。审计覆盖 141 个技能入口、1,106 份会话 JSONL，去重后 148,058 次工具调用；细分命令统计来自 81,512 条 commandExecution 投影。云端未取得的历史不计入覆盖范围，调用频率不是收益百分比。

| 已观察的方法 | 频次 | 本批实现 |
| --- | ---: | --- |
| ConvertFrom-Json / ConvertTo-Json / Python JSON | 4,823 / 6,498 / 4,275 | `data_query`：JSON、JSONL、CSV 投影、过滤、计数、分组 |
| Get-FileHash / Copy-Item / Move-Item | 1,028 / 346 / 39 | `hash_file`、`copy_file`、`move_file` |
| Get-ChildItem | 3,643 | `find_files`：复用 rg，完整扫描后排序去重并分页 |

三个智能体分别维护独立实现、行为测试及契约文档，协调者负责公共接口、构建接线、MCP 调度和最终验收。工作在独立工作树中进行，保留主工作区另一会话的改动。

## 当前边界

- [数据查询](data-query.md)只读：最大 1 MiB 解码输入，不执行脚本或通用查询语言。数字按原 token 比较与输出，CSV 单元格保持字符串。部分计数不能当成全量计数，必须检查 `scan_complete`。
- [文件操作](file-operations.md)只针对普通文件：流式 SHA-256、无覆盖复制和支持文件系统内的原子移动。复制的元数据承诺逐平台列明。Linux 复制要求目标文件系统支持硬链接，移动要求支持无覆盖 `renameat2`；不做跨卷复制删除回退。
- [文件发现](file-discovery.md)复用调用方提供的 rg。完整扫描有独立大小、数量及时间预算；未完成扫描不伪装成可分页的完整集合。每次重新扫描，offset 不承诺跨请求快照稳定性。

开发版新增 5 个工具，总数 32。现有安装连接仍按其已加载运行时提供工具；本批完成源码与本地验证不代表已经发布或替换安装版。

## 验收

`eng/test-capability-gaps.cmd` 和 `eng/test-capability-gaps-linux.sh` 执行三组原生行为测试，并接入原有 `eng/test.cmd` / `eng/test-linux.sh`。真实 MCP 测试检查工具表、精确大整数、CSV 文件、部分 JSONL、二进制哈希、复制碰撞、移动、rg 分页及异步取消。Windows 保留 MSVC C11 `/W4 /WX`；Linux 保留现有 GCC 门禁。

| 验证 | Windows | Linux ext4 |
| --- | --- | --- |
| 三组新增原生检查：数据 / 文件操作 / 文件发现 | 52 / 35 / 17，通过 | 54 / 38 / 20，通过 |
| 真实 MCP 检查 | 155/155 | 155/155 |
| Git/rg 适配器 | 26/26 | 29/29 |
| 完整构建与测试门禁 | `eng/test.cmd`，exit 0 | `eng/test-linux.sh`，exit 0 |
| 内存检查 | ASan 通过 | ASan+UBSan 通过 |
| 便携包与包内示例 | 通过 | 454 项检查通过 |

两种便携包均含 57 个 payload 文件、59 个 SPDX 文件项及 60 个归档项。签名、发布和安装替换未执行。一次 Windows 全套运行遇到既有 ANCS 超短超时用例失败，未修改该用例；原样完整重跑通过，原失败日志保留。

MSVC `/analyze /W4 /WX` 仍有一条未关闭的 C6001，位于 `data_query.c` 分组值释放处。所有权复核和 sanitizer 未复现未初始化访问，但这不能证明告警误报；未添加告警抑制，也未为消除告警保留无依据的改写。普通 `/W4 /WX` 构建通过，静态分析不能标记为通过。

本机 WSL 的 Windows 挂载盘不支持所需无覆盖移动，并会在时间设置成功后舍入纳秒部分。复制用 `metadata_checked` / `metadata_preserved` 报告约定字段的实际回读结果。该挂载盘检查通过数据 54/54、文件操作 39/39、发现 19/19，非法字节文件名因文件系统无法原样表示而单项 NOT_RUN；ext4 的 20/20 覆盖真实非法字节名与移动成功路径。Linux 原生 rg 的临时测试程序仅放在忽略的构建目录，复用项目既有的外部 rg 契约。详细证据与保留日志见 [HANDOFF](../HANDOFF.md)。
