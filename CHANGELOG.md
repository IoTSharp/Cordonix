# Cordonix Changelog

## Unreleased

### Added

- Initial Cordonix product charter and documentation baseline.
- Cordonix short form `cdx` and CDX roadmap identifiers.
- Windows-first, cross-platform-aware architecture and quality gates.
- Native C11 `cdx.exe` with JSON request mode and persistent MCP stdio mode.
- Windows process ownership, literal argv, bounded output, cancellation and whole-Job cleanup.
- Session documents with exact SHA/count edits, repeated memory reads/search and explicit single-file commits.
- Strict UTF-8, UTF-8 BOM, UTF-16LE/BE BOM and explicit CP936/GBK preservation and lossless transcoding.
- Native process, file, JSON and real stdio tests; Windows GitHub Actions build and artifact.
- Apache-2.0 license, contributor guidance, security scope, English and Chinese README.
